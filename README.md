# Firebase Product Management

React product management exercise with Firebase integration.

## Project structure

- `src/components/ProductManagement.jsx`
- `src/firebase.js`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/firebase-database.git
cd firebase-database
```

Configure your own Firebase project and appropriate database security rules before running the app.

Install Node.js and npm, then run `npm install` and `npm run dev` in the application directory. Open the terminal URL.
